# Random forest for `satisfied`

`train_rf.R` fits a random forest with `satisfied` as the dependent variable and
every other column as an independent variable, then writes predictions for the
same rows it trained on.

## Run it

```sh
Rscript train_rf.R testdata.csv predictions.csv
```

Both arguments are optional; they default to `testdata.csv` and
`predictions.csv`.

## Requirements

```r
install.packages("ranger")        # or: install.packages("randomForest")
```

On Debian/Ubuntu without CRAN access: `apt-get install r-cran-ranger`.

## Why ranger instead of party

`party::cforest` builds conditional inference forests, which are worth using
when you need unbiased variable importance across predictors with very
different numbers of categories. For straight prediction it is slow — often
one to two orders of magnitude slower than `ranger` on the same data — and it
does not give you out-of-bag predictions as directly.

`ranger` is a modern C++ implementation of Breiman's random forest: same
algorithm as `randomForest`, much faster, with permutation importance and a
separate probability forest for calibrated class probabilities. The script
falls back to `randomForest` automatically if `ranger` is not installed.

## What the script does

- Drops row-identifier columns (`X`, `id`, `index`, …) so the forest cannot
  memorise them.
- Picks the task automatically: classification when `satisfied` is
  non-numeric or has 10 or fewer distinct values, regression otherwise.
- Turns character columns and small integer codes (10 or fewer distinct whole
  numbers — survey scales, essentially) into factors.
- Drops constant columns and imputes missing predictors (median for numerics,
  most frequent level for factors), so no input row is dropped.
- Rows with a missing `satisfied` value are predicted but not trained on.
- Fits 1000 trees, `mtry = sqrt(p)` for classification and `p/3` for
  regression.

## Output

`predictions.csv` is the input file, same rows in the same order, plus:

| column | meaning |
| --- | --- |
| `pred_in_sample` | prediction from the full forest |
| `pred_oob` | out-of-bag prediction — only trees that never saw the row |
| `prob_in_*` | in-sample class probabilities (classification) |
| `prob_oob_*` | out-of-bag class probabilities (classification) |
| `correct_oob` | whether `pred_oob` matched the actual value |

It also writes `rf_model.rds` and prints the out-of-bag error, permutation
variable importance, and both confusion matrices to the console.

**Read the out-of-bag column, not the in-sample one.** Predicting the training
data with a random forest gives near-perfect accuracy — every row helped grow
almost every tree that then votes on it. On the example data below the split is
100% in-sample versus 82% out-of-bag; the second number is the honest one.

## Example

`example_data.csv` is synthetic survey data (400 rows) generated by
`make_example_data.R`, included so the script is runnable as-is:

```sh
Rscript train_rf.R example_data.csv example_predictions.csv
```

It is *not* real data — replace it with your own `testdata.csv`.
